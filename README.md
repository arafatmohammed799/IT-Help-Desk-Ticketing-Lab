# IT Help Desk Ticketing System — Spiceworks Lab

## Overview
Simulated Tier 1 IT help desk environment using Spiceworks 
Cloud Help Desk, integrated with an Active Directory home lab.

## Activities Completed
- **Ticket Creation** — Hardware, Software, and Network tickets
  with proper priority classification
- **Account Lockout** — Unlocked domain user in Active Directory,
  initiated remote session via Zoho Assist  
- **Wi-Fi Resolution** — Diagnosed expired domain certificate,
  renewed and confirmed fix with user
- **Escalation** — Escalated database issue to DB Admin team
  with full documentation and SLA communication

## Tools Used
- Spiceworks Cloud Help Desk
- Active Directory (Windows Server 2022)
- Zoho Assist (Remote Support)
- VirtualBox
